## Sobre o projeto

O **Amanda's Workspace** é uma solução desenvolvida sob demanda para uma profissional da área de administração de e-commerce, com o objetivo de centralizar ferramentas, plataformas e recursos utilizados na rotina operacional, otimizando a organização das atividades diárias, reduzindo a quantidade de abas abertas no navegador e facilitando o acesso aos principais links e ferramentas de trabalho em um único ambiente personalizado.

A interface foi desenvolvida considerando as necessidades da cliente, priorizando organização, acessibilidade e uma experiência de uso intuitiva, com identidade visual personalizada (que, inclusive, revela um gosto em comum entre nós: o universo do terror! 👻 rs)

## Tecnologias
